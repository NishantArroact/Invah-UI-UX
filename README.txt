Invah — Desktop homepage designs (HTML export)

Open index.html in Chrome or Edge, then choose a page:
  1-homepage-sharp.html       Homepage, sharp-corner version
  2-popup-open-sharp.html     Same page with the enquiry popup open
  3-homepage-rounded.html     Homepage, rounded version
  4-popup-open-rounded.html   Same page with the rounded enquiry popup open

Keep the folder together: every page needs support.js and the assets folder beside it.
An internet connection is needed for the Questrial fallback font (Google Fonts);
Century Gothic and Helvetica are used automatically where installed.
Scroll-linked animations run in Chrome and Edge; other browsers show the page without them.
